# Cassandra

Оверлей-переводчик внутриигрового чата для Windows. Захватывает область экрана с чатом, распознаёт текст,
переводит его на ваш язык и показывает в компактном окне поверх игры. Можно и ответить: напишите по-русски,
получите английский текст, вставьте его в чат игры.

- **Всё локально.** Распознавание и перевод идут на вашем компьютере. Кадры экрана хранятся только в памяти,
  на диск не пишутся, в интернет не уходят.
- **Лёгкий.** Приложение весит около 30 МБ. Модель перевода скачивается отдельно, один раз, и вы выбираете какую.
- **Не мешает игре.** Когда в чате ничего не меняется, нагрузка на процессор около 0,3% одного ядра.

## Установка

1. Скачайте [Cassandra-win-Setup.exe](https://github.com/skorjin/Cassandra/releases/latest/download/Cassandra-win-Setup.exe) (всегда последняя версия; все релизы на странице [Releases](https://github.com/skorjin/Cassandra/releases))
   и запустите. Нужны Windows 10/11 x64; .NET 10 установщик поставит сам.
2. При первом запуске выберите модель перевода и нажмите «Скачать» (см. ниже).
3. Поставьте игру в режим **«Окно без рамки»**. Поверх эксклюзивного полноэкранного режима оверлей не виден.

Приложение само проверяет обновления при запуске. Если есть новая версия, на шестерёнке появится точка;
в настройках нажмите «Установить», и приложение перезапустится. Модели обновляются отдельно от приложения.

Windows SmartScreen может показать предупреждение «неизвестный издатель»: сборки пока не подписаны цифровой подписью.
Нажмите «Подробнее» → «Выполнить в любом случае».

## Модели перевода

Модель нужна для перевода и скачивается из интернета один раз. Дальше интернет не нужен.

| Модель | Размер | Что получаете |
|---|---|---|
| Быстрая (int8) | около 220 МБ | меньше памяти и быстрее, перевод немного проще |
| Точная (fp32) | около 840 МБ | лучше качество, в несколько раз больше размер и память |

Обе включают оба направления (EN→RU и RU→EN). Выбор и загрузка находятся в настройках (шестерёнка):

- Перед загрузкой показывается размер и просьба подтвердить.
- Загрузку можно **приостановить** и продолжить позже, в том числе после перезапуска приложения или компьютера:
  скачанное сохраняется.
- Если **пропала сеть**, приложение само повторяет попытки (через 2, 5, 10, 20, 30 секунд). Если связи нет слишком долго,
  загрузка встаёт, а скачанное остаётся. Нажмите «Продолжить», когда сеть вернётся.
- Каждый файл проверяется по контрольной сумме SHA-256; повреждённые не устанавливаются.
- Можно держать обе модели и переключаться между ними, пока идёт перевод. Старая модель работает, пока не докачается новая.
- Скачанные модели лежат в `%LocalAppData%\CassandraData\models` и сохраняются при обновлении и переустановке приложения.

## Использование

1. Перетащите пунктирную рамку на чат игры. Углы рамки меняют её размер. Чтобы двигать рамку, нажмите кнопку с уголками в окне
   (`Ctrl+Alt+E`); перевод при этом продолжается. Пока рамка не разблокирована, клики и прокрутка проходят сквозь неё
   в чат игры.
   Русский текст в чате остаётся как есть, переводится только то, что написано не на вашем языке.
2. В окне показан перевод того, что сейчас видно в рамке: когда чат прокручивается или меняется, окно обновляется
   под новый кадр, а не дописывает строки к старым. Наведите курсор на строку, чтобы увидеть оригинал.
   Текст можно выделить мышью и скопировать `Ctrl+C`: окно на это время получает фокус, а после копирования
   (или `Esc`) возвращает его в игру.
3. **Пауза** только останавливает перевод, чтобы спокойно прочитать.
4. **Карандаш** открывает и закрывает панель с двумя вкладками, выбранная вкладка запоминается:
   - **Оригинал:** исправьте опечатки распознавания и нажмите «Перевести».
   - **Мой ответ:** напишите текст, получите перевод и нажмите «Копировать». Фокус вернётся в игру,
     остаётся открыть чат и нажать `Ctrl+V`.

   Пока панель открыта, перевод стоит на паузе; закрытие панели его возобновляет.
5. **Шестерёнка** открывает настройки во вкладках: «Вид» (прозрачность, цвет фона, размер и цвет шрифта),
   «Языки», «Модели» (выбор и загрузка модели перевода), «Версия» (обновления).

| Горячая клавиша | Действие |
|---|---|
| `Ctrl+Alt+P` | пауза / возобновить |
| `Ctrl+Alt+R` | написать ответ |
| `Ctrl+Alt+H` | скрыть / показать оверлей |
| `Ctrl+Alt+E` | править рамку захвата, не ставя перевод на паузу |
| `Ctrl+Alt+L` | блокировка кликов: клики идут в игру, рамка скрыта |

Позиции окон, прозрачность, цвет, языки и выбранная модель хранятся в `%AppData%\Cassandra\settings.json`.

Окна приложения исключены из захвата экрана, поэтому распознавание не читает собственный перевод. Для отладки
переменная окружения `CASSANDRA_SHOW_IN_CAPTURE=1` отключает это исключение.

## Как улучшить качество распознавания

Качество перевода начинается с того, насколько хорошо программа читает текст с экрана. Лучше всего помогают
настройки самого чата, не приложения:

- **Разборчивый шрифт.** Обычный шрифт без засечек и украшений, не курсив. Чем крупнее буквы, тем точнее чтение;
  слишком мелкий текст читается с ошибками.
- **Однотонный фон.** Тёмная или светлая сплошная подложка под чатом заметно лучше, чем картинка или анимация за
  текстом. Яркие пятна на фоне распознаются как буквы.
- **Контраст.** Светлый текст на тёмном фоне или наоборот. Обводка букв (контур) помогает читать текст на любом фоне.
- **Рамка только на чат.** Не захватывайте лишнее вокруг чата: значки, полосы и рисунки создают мусор.
- **Меньше переносов.** Если окно чата достаточно широкое, фразы переносятся реже, и перевод получается связнее.

Если в тексте всё равно появляются ошибки, на паузе исправьте оригинал вручную и нажмите «Перевести».

## Сборка из исходников

Нужен .NET 10 SDK.

```powershell
dotnet build
dotnet test                       # первый запуск скачивает «Быструю» модель (около 220 МБ) в кеш тестов
dotnet run --project src/Cassandra.App
```

Тесты на реальной модели можно пропустить: `dotnet test --filter "FullyQualifiedName!~RealModelTests"`.

## Выпуск версии

Релизы собирает [Velopack](https://velopack.io) и публикует в GitHub Releases.

```powershell
dotnet tool install -g vpk --version 1.2.161
.\tools\release.ps1 -Version 1.0.1                      # собрать локально в artifacts/releases
.\tools\release.ps1 -Version 1.0.1 -Upload -Token <PAT>  # и опубликовать на GitHub
```

Либо отправьте тег `v1.0.1`: workflow `.github/workflows/release.yml` соберёт и опубликует релиз сам.

**Каталог моделей** (`catalog/models.json`) встроен в приложение и дополнительно читается из репозитория, поэтому
новую версию модели можно выпустить, не обновляя приложение: измените `tools/generate-catalog.ps1`,
запустите его и закоммитьте результат.

## Архитектура

Слои зависят только внутрь; каждый класс отвечает за одну задачу. Подробности в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

```
Domain          модели и интерфейсы, без зависимостей
Application     конвейер, детектор изменений, цикл захвата, менеджер моделей, настройки
Infrastructure  GDI-захват, Tesseract, Marian/ONNX, загрузчик моделей, Win32, Velopack
Presentation    WPF: Views + ViewModels (MVVM, CommunityToolkit.Mvvm)
App             точка входа и сборка зависимостей (DI)
```
